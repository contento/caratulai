# Profile Comparison: Visual Examples

How the same concepts render differently across the 7 profiles. Shows the aesthetic and philosophical choices embedded in each.

---

## Example 1: Concept = "journey"

### sagan (Archival, cosmic)

```
Golden background (#d4af37)
├─ Large circle center: "destination" (silver #c0c0c0)
├─ Curved path from edge to circle: "voyage" (silver line)
└─ 3 small circles along path: "waypoints" (silver dots)

Total: ~8 elements
Tone: Voyager Golden Record. Technical, scientific. "A message about travel sent to aliens."
```

**Feel:** Timeless, profound, minimal. The journey is *data*—charted, symbolic, eternal.

---

### picasso (Elegant restraint)

```
White background
├─ Single curved line: journey path
├─ Small circle (1 line stroke): starting point
├─ Slightly larger circle (1 line stroke): destination
└─ Diagonal accent line: forward momentum

Total: ~4 elements
Tone: Minimalist sophistication. "One elegant line tells the whole story."
```

**Feel:** Sophisticated, understated. The journey is *art*—every stroke intentional, nothing wasted.

---

### contento (Visual abundance)

```
Rich background with gradient
├─ Winding path with multiple curves
├─ 15+ small circular waypoints along the path
├─ Semi-transparent overlays for "time passing"
├─ Decorative circles, spirals, and flourishes
├─ Color palette: blues, greens, oranges, purples
└─ Layered groups suggesting depth

Total: ~70–80 elements
Tone: "Celebrate all the richness. Show every detail, every color, every possibility."
```

**Feel:** Joyful, abundant, maximalist. The journey is *experience*—colorful, layered, full of detail.

---

### **freud** (Unconscious drives)

```
Grayscale + sepia layers
├─ Outermost gray ring: superego judgment ("Should I go?")
├─ Middle sepia layer: ego reasoning ("How do I go?")
└─ Innermost sepia spiral: id desire ("I WANT to go!")
    ├─ Path coils inward then outward: repression then eruption
    ├─ Darkening edges: unconscious barriers
    └─ Fading lines: forgotten memories of past journeys

Total: 50–60 elements
Tone: "Journey as psychological conflict. Desire vs restraint. What drives us beneath consciousness?"
```

**Feel:** Introspective, conflicted, mysterious. The journey is *internal*—a struggle between desire (warm sepia id) and moral judgment (cool gray superego). The path isn't linear; it coils and doubles back, showing repression and resistance.

**Key difference from sagan:** Where sagan says "The journey is data," freud says "The journey is *desire masquerading as choice.*"

---

### **jung** (Collective archetypes)

```
256-color, radial mandala
├─ Central gold circle: the Self (wholeness, integration)
├─ First ring: Hero archetype (ascending, sword-like form, red)
├─ Second ring: Shadow (dark serpent, opposite side, black/purple)
├─ Third ring: Wise Old Man (owl in blue), Anima (dove in pink)
└─ Outer ring: Sacred geometry (hexagon), binding them together

Total: ~45–50 elements
Tone: "Journey as individuation. Meeting the archetypes within. Integration of opposites."
```

**Feel:** Mythic, sacred, integrated. The journey is *spiritual*—a progression through archetypal encounters toward wholeness (the Self at center). The circular, mandala structure suggests *cycles, return, and unity*.

**Key difference from freud:** Where freud shows *conflict and repression*, jung shows *meeting and integration*. The Hero and Shadow don't fight; they're held in sacred geometry together. The journey is toward wholeness, not toward eruption.

---

### **dictionary** (Semantic reuse)

```
256-color, from vocabulary library
├─ Primitive: "traveler" shape (human-like figure, 3 lines)
├─ Pose: "walking" (legs in motion, stored pattern)
├─ Scene: "landscape" with path, mountains, waypoints
└─ Relationships: "traveler walking along path toward mountain"

Total: ~40–60 elements, reused/composed
Tone: "Build scenes from semantic primitives. Every journey is a *noun-phrase* composed of stored concepts."
```

**Feel:** Educational, compositional, consistent. The journey is *vocabulary*—an assemblage of reusable semantic units. Same "traveler" primitive appears across many generations; visual consistency enforces semantic clarity.

---

### **nietzsche** (Genealogy of values)

```
256-color, hierarchical/cyclical
├─ Bottom (origin): "instinct to wander" (dark red, chaotic, Dionysian)
├─ Middle (becoming): arrows/flows showing value transformation
│   ├─ Left branch (slave morality): "duty to travel" (gray, restrictive, upward-pointing)
│   └─ Right branch (master morality): "will to explore" (gold, ascending, flame-like)
├─ Top (synthesis): The Übermensch traveler (integrated, dancing form, red+gold)
└─ Outer circle: "eternal recurrence"—the cycle repeats infinitely

Total: ~60–80 elements
Tone: "Trace the *genealogy* of the journey. How did wanderlust become moralized? Show the dialectic: primordial drive vs civilized duty vs transcendent will-to-power."
```

**Feel:** Philosophical, dialectical, transformative. The journey is *becoming*—a genealogy showing how raw instinct gets moralized by society, then reclaimed by the strong individual (Übermensch). Spirals suggest eternal recurrence (same journey, lived again and again).

## How Freud vs Jung Differ Philosophically

### Freud: Conflict Model

**Core idea:** Personality is driven by *repressed unconscious conflict* between desire (id), reality (ego), and morality (superego).

**In the freud profile:**
- **Concentric layers** = the three parts are *separate, nested, competing*
- **Sepia → gray → cool gray** = warm primal drive constrained by cool judgment
- **Fading edges, spirals** = repression, things hidden from consciousness
- **Claustrophobic, internalized** = the drama happens *inside*, within one mind

**Example visual:** A warm sepia spiral coiling inward (libido/desire) blocked by a gray geometric boundary (superego inhibition). The path doesn't reach the center—it gets repressed.

---

### Jung: Integration Model

**Core idea:** Personality integrates *universal archetypal patterns* from the collective unconscious. Individuation = meeting and integrating opposites (shadow, anima) toward the Self.

**In the jung profile:**
- **Radial mandala** = all parts are *unified in a whole*, around a central Self
- **Gold center** = the Self (wholeness, divine center)
- **Opposing quadrants** = Hero ↔ Shadow, Masculine ↔ Feminine, *in balance*
- **Sacred geometry** = the opposites are *held together*, not fighting
- **Expansive, cosmic** = the journey happens *outward and upward* toward integration

**Example visual:** A gold luminous center (the Self) surrounded by concentric rings. On one side, a red lion (Hero); opposite, a serpent (Shadow)—both necessary, both beautiful in the mandala. No repression; instead, conscious acknowledgment and integration.

## The Philosophical Difference

```
FREUD                           JUNG
─────────────────────────────────────────
Conflict & Repression    ↔      Integration & Individuation
Id vs Ego vs Superego    ↔      Shadow ↔ Self ↔ Anima
Vertical layers          ↔      Radial mandalas
Hidden/forgotten         ↔      Acknowledged/integrated
Introspective struggle   ↔      Transpersonal wholeness
"Fix the neurosis"       ↔      "Become yourself fully"
```

## Why This Matters for Generation

When you call `caratulai generate psyche --profile freud` vs `--profile jung`:

- **freud** prompt will emphasize: *layers, conflict, repression, internalized struggle, hidden drives*
  - LLM generates: nested shapes, fading edges, warm-inside/cool-outside color shifts, claustrophobic composition
  
- **jung** prompt will emphasize: *wholeness, archetypes, integration, sacred symmetry, conscious acknowledgment*
  - LLM generates: radial/mandala layout, luminous center, opposing elements in balance, expansive composition

Same input concept ("psyche"), radically different SVG output due to the *philosophical framework* baked into the prompt.
